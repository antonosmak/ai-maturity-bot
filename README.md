# AI Maturity Telegram Bot — прототип v0.1

Прототип Telegram-бота для оцінювання AI-зрілості органу публічної влади за авторською матрицею D1–D8 (48 діагностичних тверджень).

## Що вже працює

- покрокове оцінювання 48 показників за шкалою 0–5;
- автоматичний розрахунок D1–D8 та інтегрального AIMI;
- визначення рівня AI-зрілості;
- радарна діаграма профілю AI-зрілості;
- фінальна оцінка відповідності результату фактичному стану (1–5) + коментар;
- журнал оцінювань у SQLite;
- JSON audit log для кожного оцінювання;
- рекомендації за слабкими D1–D8;
- опційний LLM-модуль рекомендацій через OpenAI Responses API.

## Команди

- `/start` або `/help` — довідка;
- `/new` — нове оцінювання;
- `/status` — стан поточного оцінювання;
- `/log` — останні 10 оцінювань;
- `/report [ID]` — звіт і радарна діаграма;
- `/recommend [ID]` — рекомендації;
- `/export [ID]` — JSON audit log;
- `/cancel` — скасувати активне оцінювання.

## 1. Створити Telegram-бота

У Telegram відкрийте **@BotFather**, виконайте `/newbot`, задайте назву та username і скопіюйте Bot Token.

## 2. Підготувати Python

Рекомендовано Python 3.11+.

```bash
python -m venv .venv
# Windows
.venv\\Scripts\\activate
# Linux/macOS
source .venv/bin/activate

pip install -r requirements.txt
```

## 3. Задати змінні середовища

### Windows PowerShell

```powershell
$env:TELEGRAM_BOT_TOKEN="ВАШ_TOKEN"
# необов'язково для AI-рекомендацій:
$env:OPENAI_API_KEY="ВАШ_OPENAI_KEY"
$env:OPENAI_MODEL="НАЗВА_ДОСТУПНОЇ_ВАМ_МОДЕЛІ"
python bot.py
```

### Linux/macOS

```bash
export TELEGRAM_BOT_TOKEN="ВАШ_TOKEN"
export OPENAI_API_KEY="ВАШ_OPENAI_KEY"   # необов'язково
export OPENAI_MODEL="НАЗВА_ДОСТУПНОЇ_ВАМ_МОДЕЛІ"  # необов'язково
python bot.py
```

Якщо OpenAI API не налаштовано, бот все одно повністю працює; рекомендації формуються детермінованими правилами з оцінок D1–D8.

## Формула

Для кожного виміру:

`D_i = sum(x_ij) / (5*n_i) * 100`

У поточній матриці у кожному D по 6 тверджень. Інтегральний індекс використовує рівні ваги 0.125:

`AIMI = (D1 + ... + D8) / 8`

Рівні: 0–20 — I; >20–40 — II; >40–60 — III; >60–80 — IV; >80–100 — V.

## Дані та журнал

SQLite база створюється автоматично у `data/ai_maturity.db`.

Кожна оцінка зберігається окремим записом; завершене оцінювання не перезаписується. `/export ID` формує audit log у JSON.

## Наступна версія (v0.2)

Доцільно додати автоматичне попереднє оцінювання за відкритими даними:

1. користувач вводить URL/назву органу;
2. модуль дослідження збирає відкриті докази;
3. AI формує `score + evidence + confidence` для автоматично верифікованих критеріїв;
4. бот ставить лише питання, яких не можна достовірно встановити зовні;
5. AI-score та respondent-score зберігаються окремо;
6. формується `Public AI Maturity Profile` і `Verified AI Maturity Profile`.

Ключовий принцип: **відсутність відкритого доказу не дорівнює нульовій зрілості**. Для таких позицій має використовуватися статус `NE / insufficient evidence`.
