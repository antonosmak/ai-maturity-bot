# AI Maturity Telegram Bot — v0.3

Три режими оцінювання:
1. **ШІ-аналіз** — назва органу + офіційний URL; ШІ оцінює доступні показники, невизначені залишає ND.
2. **ШІ-аналіз з підкріпленням** — ШІ робить первинний аналіз, респондент відповідає лише на ND.
3. **Ручне оцінювання** — 48 показників вручну.

## Нові змінні Render
Для режимів 1–2 обов'язково:
- `OPENAI_API_KEY`
- `OPENAI_MODEL` (наприклад модель, доступна вашому API-акаунту)

Існуючі `TELEGRAM_BOT_TOKEN`, `TELEGRAM_WEBHOOK_SECRET`, `GDRIVE_UPLOAD_URL`, `GDRIVE_UPLOAD_SECRET` зберігаються.

## Оновлення
Замініть `bot.py` і `requirements.txt`. `app.py`, `matrix.json`, `render.yaml` залиште з v0.2.2.

Після деплою `/new` показує три окремі кнопки режимів.
